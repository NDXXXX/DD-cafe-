# Product scope

## Goal

Demonstrate that a restaurant guest can browse a normal menu, ask a warm conversational assistant what to order, add and change items safely, submit an order, and continue asking restaurant questions afterward.

## Included in V1

- Mobile-first web application.
- Traditional menu browsing and draft cart actions.
- SSE-streamed conversation.
- Read-only recommendation agent.
- Constrained order agent.
- Restaurant and menu RAG with CRUD, hybrid retrieval, and reranking.
- Real-time web-search tool for external information.
- Immutable submitted orders, addendum orders, and pending cancellation requests.
- Runtime and evaluation harness.

## Not included in V1

- QR-code generation or scanning.
- Real payment.
- Kitchen integration.
- Staff approval workflow.
- Multi-store tenancy.
- User accounts or long-term customer profiles.
